# CEFR-Guided Content Creation with GitHub Copilot Agents

**Purpose**: This guide explains how to use custom GitHub Copilot agents to create CEFR-aligned German language learning content from outline templates.

**Key Principle**: Agents don't just review existing YAML files—they CREATE the YAML data files themselves based on outlines extracted from German language textbooks.

## Workflow Overview

1. **User provides**: `outline.yml` file summarizing content to be learned at a specific CEFR level (extracted from textbooks)
2. **Project Manager**: Plans album structure and groups content into logical parts
3. **Specialist Agents**: Create the actual YAML track files with examples, translations, and audio text
4. **Import**: Load completed YAML into Django database with confirmation prompt

---

## Quick Start

### Creating a New Grammar Album

Open GitHub Copilot Chat and provide the Project Manager with an outline:

```text
@project-manager I have an outline.yml file at data/b1/grammar/outline.yml with 5 grammar topics for B1 learners.

Please:
1. Review the outline and plan album/track structure
2. Group related topics logically
3. Create YAML track files by coordinating with @cefr-specialist, @german-teacher, and @native-speaker
4. Each track should have 8-10 examples with German text, English translations, and natural phrasing

Target: 1-2 albums, 5-8 tracks per album, appropriate for B1 level.
```

The Project Manager will:

1. Analyze the outline and propose album structure
2. Coordinate the three specialist agents to create each YAML track file
3. Ensure consensus (CEFR Specialist + German Teacher must agree; Native Speaker is advisory)
4. Deliver completed YAML files ready for import

---

## Agent Roles in Content Creation

Three specialist agents collaborate to create CEFR-aligned content:

### @cefr-specialist
**Focus**: Validates CEFR level alignment

**Review Criteria**:
- Vocabulary matches target level (B1 = ~1500-2000 words, familiar daily topics)
- Grammar structures are appropriate (B1 = past/future tenses, modal verbs, relative clauses)
- Task complexity aligns with level (B1 = simple communication, routine exchanges)

**Example prompt**:
```
@cefr-specialist Assess whether the vocabulary and grammar in data/b1/grammar/core/tracks/track-01.yml 
are appropriate for CEFR B1 learners. Flag any concepts that are too advanced (B2+) or too simple (A2).
```

---

### @german-teacher
**Focus**: Validates pedagogical soundness and grammar accuracy

**Review Criteria**:
- Grammar is correct and exemplifies the target concept
- Examples progress logically from simple to complex
- Common learner errors are anticipated and addressed
- Exercises support the learning objective

**Example prompt**:
```
@german-teacher Review data/b1/grammar/core/tracks/track-02.yml for pedagogical quality.
Are the examples clear? Does the progression make sense? Are there potential confusion points 
for English speakers learning German?
```

---

### @native-speaker
**Focus**: Validates naturalness and real-world usage (advisory)

**Review Criteria**:
- Phrases sound natural and idiomatic
- Register (formal/informal) is appropriate for context
- Expressions reflect contemporary German usage
- Colloquialisms or regional variants are flagged

**Example prompt**:
```
@native-speaker Do the example sentences in data/b1/grammar/core/tracks/track-03.yml sound natural? 
Are there more common ways Germans would express these ideas in everyday conversation?
```

---

## Consensus Rule (Guidance for Prompt Text)

The recommended weighted consensus rule is:

- **CEFR Specialist** + **German Teacher** must agree → content approved for import
- **Native Speaker** input is advisory (dissent noted but doesn't block)

If CEFR Specialist or German Teacher requests changes, revise content and re-review.

## Content Creation Workflow

### Step 1: Provide Outline to Project Manager

**For Grammar Albums** (most common):

Provide the PM with an `outline.yml` file extracted from genuine German textbooks:

```yaml
# Example: data/b1/grammar/outline.yml
level: B1
topics:
  - Reflexive Verbs
  - Dative Case
  - Modal Verbs (können, müssen, wollen)
  - Subordinate Clauses (weil, dass, wenn)
  - Past Tense (Perfekt)
```

**Request to Project Manager**:

```
@project-manager I have an outline.yml file at data/b1/grammar/outline.yml with 5 grammar topics for B1 learners.

Please:
1. Review the outline and plan how to structure these into albums/tracks
2. Group related topics logically (e.g., verb-focused vs case-focused)
3. Create 1-2 albums with appropriate track structure
4. Delegate creation of YAML track files to @cefr-specialist, @german-teacher, and @native-speaker

Each track should include:
- German examples demonstrating the grammar point
- English translations
- Natural, level-appropriate vocabulary
- Progression from simple to complex usage

Target: 5-8 tracks per album, each focusing on one aspect of the grammar topic.
```

### Step 2: Project Manager Plans Structure

The PM analyzes the outline and proposes album structure:

**Example PM Response**:
> I'll create two albums:
> 
> **Album 1: B1 Verbs & Actions** (3 topics)
> - Track 1: Reflexive Verbs basics (sich waschen, sich anziehen)
> - Track 2: Reflexive Verbs with emotions (sich freuen, sich ärgern)
> - Track 3: Modal verbs (können, müssen, wollen)
> - Track 4: Modal verbs in context
> 
> **Album 2: B1 Sentence Structure** (2 topics)  
> - Track 1: Subordinate clauses with "weil"
> - Track 2: Subordinate clauses with "dass" and "wenn"
> - Track 3: Past tense (Perfekt) formation
> - Track 4: Past tense (Perfekt) in conversation

### Step 3: Agent Collaboration Creates Files

PM coordinates the three specialist agents to create each track file:

**For each track**, PM facilitates:

```
@project-manager Create data/b1/grammar/verbs-actions/tracks/track-01.yml for "Reflexive Verbs basics".

Coordinate with:
- @cefr-specialist: Ensure examples match B1 complexity
- @german-teacher: Verify grammar accuracy and pedagogical progression  
- @native-speaker: Ensure phrases sound natural

Create 8-10 example sentences showing reflexive verbs in context.
```

**Agent Collaboration**:

1. **CEFR Specialist** proposes vocabulary and complexity level
2. **German Teacher** drafts example sentences with grammar explanations
3. **Native Speaker** reviews for naturalness and suggests adjustments
4. **PM** consolidates into final YAML file

### Step 4: Review Agent Feedback

Agents provide feedback in plain language:

**Example CEFR Specialist feedback**:
> ✓ Vocabulary is appropriate for B1 (daily routines, common verbs)
> ⚠️ Track 3 uses "obwohl" (subordinating conjunction) - borderline B1/B2
> ✗ Track 5 includes Konjunktiv II (B2+ concept) - too advanced

**Example German Teacher feedback**:
> ✓ Grammar examples are accurate and progress logically
> ⚠️ Track 2, Part 3: English speakers may confuse "seit" vs "vor" - add clarifying note
> ✓ Exercises align well with learning objectives

**Example Native Speaker feedback**:
> ✓ Most phrases sound natural and contemporary
> ⚠️ Track 4, Part 1: "Ich hätte gern" is correct but slightly formal; "Ich möchte" is more common
> ⚠️ Track 4, Part 5: "Das macht nichts" is fine but regional; consider "Kein Problem"

### Step 5: Iteration & Refinement

If agents suggest changes:

```
@project-manager The native speaker suggested "Ich möchte" instead of "Ich hätte gern" for Track 4.
Please update data/b1/grammar/verbs-actions/tracks/track-04.yml accordingly and regenerate the file.
```

PM coordinates updates and ensures all agents agree on final version.

### Step 6: Import with Confirmation

Before importing, the CLI will show a confirmation prompt:

```bash
python run_import.py --yaml b1/grammar/core
```

This reminds you to run agent reviews before proceeding with import.

---

## Iteration & Re-Review

If you edit YAML content after review:

1. **Minor edits** (typos, voice changes): No re-review needed
2. **Content changes** (new examples, grammar changes): Re-review recommended
3. **Level changes**: Always re-review

The CLI will remind you to re-run review before import.

## CEFR Level Guidelines

### A1 (Beginner)
- **Vocabulary**: ~500 basic words (greetings, numbers, common nouns)
- **Grammar**: Present tense, basic word order, simple questions
- **Tasks**: Introduce yourself, order food, ask for directions

### A2 (Elementary)
- **Vocabulary**: ~1000 words (daily routines, shopping, family)
- **Grammar**: Past tense (Perfekt), possessives, basic conjunctions
- **Tasks**: Describe past events, make simple comparisons, express opinions on familiar topics

### B1 (Intermediate)
- **Vocabulary**: ~2000 words (work, hobbies, current events)
- **Grammar**: Future tense, modal verbs, relative clauses, subordinating conjunctions
- **Tasks**: Narrate experiences, explain plans, handle most travel situations

### B2 (Upper Intermediate)
- **Vocabulary**: ~4000 words (abstract concepts, nuanced expressions)
- **Grammar**: Konjunktiv II, passive voice, advanced conjunctions
- **Tasks**: Argue a position, understand complex texts, interact spontaneously

### C1 (Advanced)
- **Vocabulary**: ~8000 words (idiomatic, professional, literary)
- **Grammar**: Advanced structures, stylistic variations
- **Tasks**: Express ideas fluently, understand implicit meaning, use language flexibly

### C2 (Proficiency)
- **Vocabulary**: Near-native command
- **Grammar**: All structures, including regional and archaic forms
- **Tasks**: Summarize complex information, discuss abstract topics at expert level

## Troubleshooting

### Agent Disagreement

If CEFR Specialist and German Teacher disagree:

1. **Project Manager** mediates based on weighted rule
2. Prioritize **CEFR integrity** over pedagogical preference if conflict arises
3. Record dissent and reasoning in review notes

### Ambiguous Content (Spans Multiple Levels)

If content includes B1 and B2 concepts:

- Split into separate tracks by level
- Or label as "B1/B2 transition" and target higher level

### Agent Unavailable or Delayed

If agents don't respond promptly:

- Proceed with available agent feedback
- Document which agents were consulted
- Re-review when full coverage is available
